설정 열기

홈 화면 오른쪽 위의 톱니바퀴를 탭하세요. 설정이 오른쪽에서 밀려 들어오고, ‹를 탭하면 닫혀요. 키보드를 연결한 iPad에서는 ⌘,를 누르세요.

전시실

  1. 갤러리: 화면 모드. 낮은 조명이 비추는 따뜻한 벽, 밤은 짙은 차콜빛 전시실, 자동은 iPhone의 라이트·다크 모드 설정을 따라요.
  2. 세션 중: 배경 음악, 효과음, 햅틱 피드백.
  3. 나의 하루 의식: 매일 집중(오늘의 명화 위젯의 안개를 걷어내는 목표)과 매일 알림.
  4. 응원하기: 후원자 되기와 토요일 메모.
  5. Easel 소개: 언어, 만든 사람 소개, 소개 다시 보기, 개인정보 처리방침, 의견 보내기.

언어

Easel은 영어, 폴란드어, 스페인어, 프랑스어, 중국어(간체), 힌디어, 일본어, 한국어, 브라질 포르투갈어를 지원해요. 설정에서 언어를 탭하면 iOS의 Easel 설정 페이지가 열리고, 원하는 언어를 고르면 Easel이 새 언어로 다시 시작돼요.
